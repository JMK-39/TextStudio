# Text Studio

> V1.0

## 简体中文

提供动态文字效果、名称样式和聊天界面增强。

### 核心功能

- 支持渐变、彩虹、波浪、扫光、打字、抖动和故障等文字效果，可实时预览与保存预设。
- 设置玩家显示名称及效果；部分高级名称特效受权限限制。
- 扩展聊天长度与历史记录，支持时间戳、滚动条、复制、重复消息合并及聊天头像。

### 使用

按 **F6** 打开设置与文字特效编辑器；使用 `/kt font` 或 `/kt font guide` 查看文字样式入口。客户端显示偏好保存在本地，涉及服务器的设置以服务器为准。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+。

## English

Adds animated text effects, name styling, and chat-interface improvements.

### Features

- Preview and save presets for gradients, rainbows, waves, shine, typing, shake, and glitch effects.
- Customize player display names and effects; some advanced name effects are permission-restricted.
- Extend chat length and history with timestamps, scrollbars, copying, duplicate-message grouping, and player avatars.

### Usage

Press **F6** for settings and the effect editor; use `/kt font` or `/kt font guide` for text-style options. Client display preferences are local, while server-controlled settings follow server rules.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+.
