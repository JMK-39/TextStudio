# Text Studio

## English

Text Studio combines animated text authoring, player display-name styling, and chat improvements.

### Try two animated effects on the same line

Type your announcement into the live preview. Select Elegant Wave, then Typewriter, and watch the same text change as each preset animates.

![Entering a sample line and switching the live preview from Elegant Wave to Typewriter](https://raw.githubusercontent.com/wiki/JMK-39/TextStudio/media/tutorials-20261126/en.gif)

[Editor guide](https://github.com/JMK-39/TextStudio/wiki/Text-Effects)

- Visual text-effect presets with copyable styled text.
- Custom display names, chat timestamps, avatars, and selection/copy tools.
- Longer input and persistent chat history.

Supports Minecraft **1.20.1 / Forge 47.4.2+**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) and **26.1.2 / NeoForge 26.1.2+** (validated with 26.1.2.112). Requires **Java 17** on 1.20.1, **Java 21** on 1.21.1, **Java 25** on 26.1.2, and **KineticCore 26.11.24+** matching the Minecraft/loader. Install required mods on the server and connecting clients.

### 在同一句话上试用两种动态特效

在预览框输入「遗迹已发现 · 启程」，先选「优雅波浪」，再换成「剧情打字机」。同一行文字会按选中的预设实时播放动画。

![输入试读文字，并在实时预览中先选优雅波浪、再选剧情打字机的实录](https://raw.githubusercontent.com/wiki/JMK-39/TextStudio/media/tutorials-20261126/zh.gif)
