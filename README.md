# Text Studio

## English

Text Studio combines animated text authoring, player display-name styling, and chat improvements.

**Compose text effects in one editor.** Browse color, motion, glyph and visual settings for the same preset in one scrollable editor. The preview and Copy, Prefix, Stop and Save controls stay at the top.

![TextStudio: color, motion, glyph and visual sections of one scrollable effect editor](https://raw.githubusercontent.com/wiki/JMK-39/TextStudio/media/showcase-20261126/en/text-effect-editor.gif)

*Captured editor views · Minecraft 1.20.1 Forge · One preset*

- Visual text-effect presets with copyable styled text.
- Custom display names, chat timestamps, avatars, and selection/copy tools.
- Longer input and persistent chat history.

Supports Minecraft **1.20.1 / Forge 47.4.2+**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) and **26.1.2 / NeoForge 26.1.2+** (validated with 26.1.2.112). Requires **Java 17** on 1.20.1, **Java 21** on 1.21.1, **Java 25** on 26.1.2, and **KineticCore 26.10.7+ on Forge 1.20.1 (26.10.3+ on NeoForge)** matching the Minecraft/loader. Install required mods on the server and connecting clients.

## 简体中文

Text Studio 整合动态文字制作、玩家显示名称样式与聊天增强功能。

**在同一编辑器里组合文字特效。** 在同一滚动编辑区查看一个预设的颜色、位移、单字动画和视觉参数，预览、复制、前缀、停止码与保存控件始终在顶部。

![TextStudio 实拍：同一滚动特效编辑器的颜色、位移、单字动画和视觉分区](https://raw.githubusercontent.com/wiki/JMK-39/TextStudio/media/showcase-20261126/zh/text-effect-editor.gif)

*实拍编辑器视图 · Minecraft 1.20.1 Forge · 同一预设*

- 可视化文字特效预设与特效文本复制。
- 自定义显示名称、聊天时间戳、头像与选取复制。
- 扩展输入长度与持久化聊天历史。

支持 Minecraft **1.20.1 / Forge 47.4.2+**、**1.21.1 / NeoForge 21.1+**（验证使用 21.1.252）与 **26.1.2 / NeoForge 26.1.2+**（验证使用 26.1.2.112），必需 **Java 17**（1.20.1）、**Java 21**（1.21.1）、**Java 25**（26.1.2）和与 Minecraft、加载器匹配的 **KineticCore 26.10.7+（Forge 1.20.1；NeoForge 为 26.10.3+）**。服务端与连接的客户端均安装必需模组。
